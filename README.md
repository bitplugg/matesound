# matesound

Неофициальный клиент SoundCloud для Android: Kotlin, Jetpack Compose (Material 3), Media3/ExoPlayer.

> Проект не связан с SoundCloud и не одобрен ею. «SoundCloud» — торговая марка соответствующего правообладателя.

## Возможности

- Поиск треков, артистов и плейлистов
- Чарты и тренды по жанрам
- Фоновое воспроизведение: уведомление, экран блокировки, управление с гарнитуры
- Очередь, перемешивание, повтор, скорость 0.5–2.0x
- Таймер сна
- Эквалайзер (системный, 5 пресетов)
- Библиотека: лайки, плейлисты, история прослушивания
- Страницы артистов и плейлистов
- Офлайн-загрузки: HLS-поток склеивается в один локальный файл
- OTA-обновления через GitHub Releases: автопроверка, загрузка APK и установка
- Тёмная/светлая/системная тема, Material You (цвета обоев) на Android 12+, RU + EN

## Требования для сборки

- JDK 17
- Android SDK: platform 36, build-tools 35+
- `local.properties` с `sdk.dir=/path/to/Android/Sdk` (не коммитится)

```bash
./gradlew :app:assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Release-сборка (без подписи по умолчанию):

```bash
./gradlew :app:assembleRelease
# APK: app/build/outputs/apk/release/app-release-unsigned.apk
```

Подписать локально:

```bash
apksigner sign --ks release.jks --out matesound.apk app-release-unsigned.apk
```

## Как устроен вход

SoundCloud закрыл регистрацию новых API-приложений, поэтому клиент работает так же, как мобильный веб-плеер:

1. `AuthWebViewActivity` открывает `m.soundcloud.com` в WebView.
2. Пользователь входит в аккаунт.
3. Приложение читает `oauth_token` из `localStorage` страницы (или из редиректа) и сохраняет его в DataStore на устройстве.
4. Токен используется только для запросов к API SoundCloud. Наружу он не отправляется.

Публичный `client_id` берётся из веб-плеера SoundCloud и обновляется автоматически (`ClientIdProvider`), с валидацией и фолбэком. При проблемах: Настройки → «Обновить API client id» или «Ввести токен вручную».

## Обновления (OTA)

Приложение проверяет последний релиз через GitHub API и предлагает скачать новый APK. Установка открывает системный установщик; на Android 8+ нужно разрешить установку из неизвестных источников.

- Обновление подписывается тем же debug-ключом, которым подписан APK из GitHub Releases. Если вы собрали APK локально, его debug-ключ отличается — OTA-обновление поверх него не установится.
- Проверить вручную можно в Настройках → Обновления.

## Ограничения

- Часть треков SoundCloud отдаёт только 30-секундным превью — это ограничение платформы, а не приложения. В UI такие треки помечаются как `preview`.
- `client_id` веб-плеера может меняться; приложение умеет его перевыпускать, но полностью гарантировать стабильность невозможно.
- Офлайн-загрузка предназначена для личного прослушивания. Уважайте права авторов и условия SoundCloud.
- Приложение не является форком какого-либо существующего клиента и написано с нуля.

## Структура

```
app/src/main/java/dev/bitplugg/matesound/
├── data/
│   ├── auth/        # вход через WebView и хранение токена
│   ├── download/    # HLS → локальный файл
│   ├── local/       # DataStore + JSON-хранилище библиотеки
│   ├── model/       # модели API
│   ├── remote/      # OkHttp-клиент, поиск client_id
│   └── repo/        # репозиторий SoundCloud
├── playback/        # ExoPlayer, MediaSessionService, эквалайзер
└── ui/              # Compose: экраны, тема, вьюмодели
```

## CI

`.github/workflows/build.yml` собирает debug APK на каждый push/PR и прикладывает артефакт. На теги (`v*`) дополнительно собирается unsigned release APK и создаётся GitHub Release с обоими APK.
